# XAUUSD cross-session feature diagnostics\n\nThis offline tool compares provenance-verified XAUUSD feature-window JSON from independent DEMO sessions. It validates unique source hashes, matching feature schemas and window widths, non-overlapping UTC intervals, and exact reconciliation between per-window tick counts and source record totals.\n\nIt reports per-session feature distributions (observations, nulls, min, p05, median, p95, max), descriptive Pearson correlations, and cross-session median deltas. Sessions remain separate and are ordered chronologically. Correlations are descriptive associations only.\n\nRun:\n\n```bash\npython -m tools.mt5_xauusd_feature_diagnostics --inputs session-a.json session-b.json --output diagnostics.json\n```\n\nNo strategy selection, labels, signals, orders, profitability claims, traded-volume inference, or execution-quality inference are produced.\n
